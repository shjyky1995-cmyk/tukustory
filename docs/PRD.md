## 1. 产品定义

将建筑图集中的做法，从不便查找的 PDF 页面整理为可检索、可纠正、可追溯的本地资料条目；用户选中做法后，可将各层文字插入 AutoCAD 并独立编辑。

产品的核心管理对象是“做法”，不是整本 PDF，也不是脱离出处的 OCR 文本。原始 PDF 是每条做法的依据，需要始终保留。

第一版的完整使用链路：

**导入 PDF → 自动识别和拆分 → 按地区或部位查找 → 查看原页和编辑 → 插入 CAD → 独立编辑文字。**

## 2. 已确认的产品决策

| 事项 | 已确认要求 |
| --- | --- |
| 使用人群 | 用户本人或小团队 |
| 平台 | Windows 桌面软件 |
| 原始资料 | 以扫描 PDF 为主，同时兼容文本 PDF 和混合 PDF |
| 首批规模 | 先用 3～10 本有代表性的图集试点 |
| 地区分类 | 国标、山东、新疆等，允许扩展 |
| 部位分类 | 楼地面、内墙面、外墙面、屋面、顶棚等 |
| 数据部署 | 每台电脑独立本地资料库，资料包交换，不做实时同步 |
| 扫描识别 | 允许使用云端 OCR／AI 服务 |
| 识别后入库 | 可解析结果直接入库，使用中发现错误再修改，不设置强制审核 |
| CAD 范围 | AutoCAD 2017～2021，实际支持情况逐版本验证 |
| CAD 输出 | 名称、编号和各层说明分别成为可编辑的独立文字对象 |
| 当前交付 | PRD、技术架构、根目录 AGENTS.md；不启动软件实现 |

“未核对”是信息提示，不是禁止搜索或插入的条件。图集地区是来源分类，不代表系统已判断该做法适用于某一工程。

## 3. 用户场景

### 3.1 找到并采用一条做法

用户选择“山东”和“楼地面”，输入材料或做法编号，查看匹配结果。点开条目后，对照原页确认文字，必要时现场修改，再插入当前 CAD 图纸。

成功结果：插入内容与详情页保存的内容一致；各层文字可分别编辑、移动；来源可追溯。

### 3.2 将新图集加入资料库

用户批量选择 PDF，逐本确认名称、编号、地区、年份和处理页范围。软件自动处理，成功条目立即可查；异常页仍有原图和原因，可单独重试或手动录入。

成功结果：任务中断后可继续，不重复生成已入库记录，不丢失原文件和处理状态。

### 3.3 纠正错误而不丢失历史

用户发现 OCR 厚度、单位或层次顺序错误，对照原页编辑并保存。后续重新识别同一页面产生候选结果，不覆盖人工修改。

成功结果：可查看旧版本并恢复；恢复形成新的修订；此前已插入 CAD 的文字保持不变。

### 3.4 将资料交给同事

用户导出包含条目、原始 PDF 和修改记录的资料包，同事导入前看到新增、重复和冲突数量。

成功结果：导入后能查看原页；冲突不静默覆盖；资料包不包含 API 密钥或机器专属路径。

## 4. 第一版范围与实施优先级

P0 是第一批闭环能力；P1 是第一版交付前补齐的能力。分批实现不意味着删除第一版需求。

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| 本地图集、做法、层次与来源管理 | P0 | 支持手动录入，不能完全依赖识别服务 |
| 地区／部位／图集筛选、关键词搜索 | P0 | 两个独立分类维度，支持组合筛选 |
| 原页预览与条目编辑 | P0 | 修改立即用于之后的搜索与插入 |
| 修改历史、恢复、重识别保护 | P0 | 不覆盖人工成果 |
| 单本导入、文本提取、扫描识别 | P0 | 按页处理，记录失败与缓存 |
| CAD 独立文字插入 | P0 | 先在可用版本验证，再扩展兼容 |
| 批量导入、暂停继续、任务与异常列表 | P1 | 持久化任务状态 |
| 多做法拆分、跨页关联、手动拆分合并 | P1 | 不确定结果不得伪造完整做法 |
| 原页区域定位与手动框选建条目 | P1 | 无可靠区域时显示整页 |
| 处理量、费用估算与任务预算控制 | P1 | 预算是本地调用控制，账单以服务商为准 |
| 资料包、冲突预览、备份恢复 | P1 | 带来源与校验信息 |
| 安装、插件分版本部署与兼容测试 | P1 | 未实测版本不标记已支持 |

不包含：扫描节点详图自动矢量化、节点重绘、构造图自动生成、多人在线同步、账号计费、商业授权、工程适用性自动判断、法规有效性自动判定、语义搜索、手机端。

收藏、常用做法组合、项目专用做法、标准说明表、DWG／DXF 输出及国产 CAD 适配均留作后续需求，不在第一版擅自增加。

## 5. 信息组织与搜索

### 5.1 分类原则

- 地区归属主要记录在图集上，条目继承来源；“国标”是独立来源类别。
- 部位归属记录在做法上。第一版每条做法一个主部位，额外适用范围使用标签表达。
- 图集保存名称、编号、年份或版本说明；未知年份允许留空，不自动猜测。
- 标签可表达材料、功能和空间，例如“地砖”“防水”“卫生间”。
- 无法确定的部位进入“其他／待分类”，不能因为分类失败丢失条目。
- 图集编号不是数据库唯一键；不同年份、不同图集中的相似内容分别保留。

默认部位：楼地面、内墙面、外墙面、屋面、顶棚、其他／待分类。地区和标签允许用户新增；已有内容不会因分类重命名失去关联。

### 5.2 两个浏览入口

- 按地区：地区 → 图集 → 部位 → 做法。
- 按部位：部位 → 地区／图集筛选 → 做法。

两个入口查询同一份数据，不创建两套内容。清空筛选后恢复全库浏览。

### 5.3 搜索规则

- 搜索范围：做法名称、编号、当前分层文字、备注、标签、图集名称和编号。
- 多个空格分隔关键词采用“全部匹配”，每个词可以命中不同字段。
- 编号精确匹配优先，之后为名称匹配，再之后为正文匹配；同级结果使用稳定排序。
- 英文大小写、全角半角和连续空白在搜索索引中归一化，原始显示文字保持不变。
- 地区、部位和图集条件与搜索词同时生效；空关键词表示只筛选。
- 无结果时显示当前条件并提供清空筛选入口，不自动改写用户条件。

第一版不自动推断未输入的同义词，不自动把“墙面”扩展为所有相关专业分类。

## 6. 界面与操作要求

### 6.1 主工作区

| 区域 | 内容 |
| --- | --- |
| 顶部操作区 | 导入图集、手动新建、导入任务、资料包、设置 |
| 左栏 | 按地区／按部位切换，分类树及图集筛选 |
| 中栏 | 搜索框、结果数量、结果列表和加载状态 |
| 右栏 | 做法详情、分层内容、原页预览、编辑与 CAD 插入 |

列表至少显示名称、编号、部位、来源图集与核对状态。详情区可放大原页，也可打开完整 PDF。

编辑后切换条目时，提供保存、放弃和取消切换，不能无声丢弃修改。CAD 插入使用已保存修订；存在未保存修改时提供“保存并插入”或返回编辑。

### 6.2 详情编辑

- 可编辑名称、编号、主部位、标签、备注和引用说明。
- 层次支持增加、删除、上移、下移；显示顺序即后续插入顺序。
- 每层保存原始文字与当前文字；用户不需要理解数据库字段。
- 手动录入允许编号为空，但必须有名称及至少一项可插入正文。
- 从图集新建的条目必须关联原 PDF 页；纯自定义条目明确标记“手动创建、无图集来源”。
- PDF 实际页序与页面印刷页码分开显示，例如“PDF 第 12 页／图集标注第 8 页”。
- 原页区域使用可靠识别位置或用户框选位置；未知时不伪造高亮。
- 恢复历史版本是一次新的保存操作，历史继续保留。

### 6.3 来源与引用

每条图集做法可关联多页。编号或页码引用保留原文，仅在当前图集及版本内能唯一定位时提供跳转；未解析引用仍可阅读和插入。

“已核对”由用户明确设置，不因识别成功自动设置。修改正文或采用新识别候选后恢复“未核对”。

## 7. PDF 导入与识别需求

### 7.1 导入设置

批量选择文件后显示逐本设置表：文件名、图集名称、编号、地区、年份、页范围。允许统一设置地区后逐本修改。

页范围使用 PDF 实际页序，导入前校验越界和重复。扫描、文本和混合类型按页判断，不以整本文件单一判定。

同一文件重复导入时显示已有图集，可补充未处理页或重新识别选定页；不悄悄创建另一份相同原文件。不同文件即使名称相同也不自动覆盖。

### 7.2 处理链路

1. 将 PDF 纳入受管理的本地资料目录，记录文件指纹。
2. 提取页面文本并判断可用性；乱码、空白或明显不完整时进入图像识别。
3. 渲染扫描页，必要时分区处理；保留原页与识别输入的对应关系。
4. 识别做法边界、名称、编号、层次、备注与引用。
5. 解析并校验字段，建议分类和标签。
6. 成功条目直接入库，默认“未核对”；无法解析部分进入异常列表。

识别只整理原文，不能补写材料、数值、单位、否定词或层次。无法辨认的内容保留缺失／疑似问题提示。页面不是做法页时允许记录为“无做法内容”，但必须与处理失败区分。

### 7.3 一页多条与跨页

- 一页多个做法形成多条记录，各自保留来源范围。
- 跨页做法只有在编号、连续内容或明确续页标记支持时自动关联。
- 无足够依据时保留分段结果，提示可能续页，允许用户手动合并；不根据相似名称强行拼接。
- 手动拆分和合并保留所有来源及原始条目关系；原条目归档但仍可从历史查看，避免内容丢失。
- 原页支持框选区域新建条目；框选后可识别该区域或直接手动录入。

### 7.4 任务、重试与费用

- 任务显示已完成页数、待处理页数、异常页数、当前状态及处理日志。
- 暂停停止安排新调用，已经发出的调用允许完成并保存结果；不能承诺撤回云端已产生的费用。
- 应用关闭或崩溃后，已持久化结果仍可用，未完成任务可继续。
- 成功识别按输入内容和识别配置缓存，重试仅处理尚未成功部分。
- 网络超时保留“结果未确认”状态，避免无提示地反复调用和计费。
- 导入前显示预期云端处理页数；有可靠单价和用量依据时显示费用估算，无依据则明确“无法估算”。
- 设置预算时，仅在可计算调用上限的配置下执行预算控制；无法估算时不宣称具备金额硬上限，可改用用户设置的最大调用页数。
- 预算不足时任务暂停，不删除成果。已发出的请求可能产生费用，最终金额以服务商账单为准。

### 7.5 重新识别

重识别形成候选版本，显示与当前正文的差异，用户可采用或放弃；不自动覆盖已有条目。采用后形成新修订，保留人工修改历史和识别原始响应。

## 8. CAD 插入需求

### 8.1 操作流程

选择做法 → 点击插入 → 确认目标实例与图纸 → 切换 CAD 指定位置 → 完成插入。

一个实例且只有一个可用图纸时可以自动选定；多实例或多图纸时展示明确名称，不猜测目标。等待用户选点期间，桌面端显示等待状态并允许取消。

### 8.2 生成内容

- 名称、编号、每一层说明、非空备注和来源说明分别生成独立多行文字对象。
- 空编号或空备注不生成空对象。原引用说明作为正文保留，不自行补全引用内容。
- 层次顺序与详情页一致；不自动反转，不根据“常见做法”调整。
- 所有对象组成 CAD 组，便于整体移动；每层仍是独立可编辑对象，不创建图块封装。
- 源文字中的 CAD 格式控制符需按普通文字处理，避免改变原内容。

### 8.3 样式

用户可设置目标文字样式、字高、内容宽度、段间距和图层，保存上次设置。数值采用当前图纸单位，界面明确提示；不自动推断比例或毫米单位。

目标图纸缺少样式或图层时明确提示或使用已说明的默认方案，不静默替换中文字体。长文本自然换行，下一条位置根据实际文字高度计算，防止重叠。

### 8.4 完整性与异常

- 仅在 CAD 合法命令上下文中操作图纸，遵循当前用户坐标系。
- 用户取消、目标图纸关闭、目标切换或写入失败时不留下半成品。
- 一次撤销移除本次全部文字及组，不影响此前图纸内容。
- 返回成功时表示图纸实体已提交；未收到响应不能当作成功，也不能直接重发导致重复插入。
- 资料库修改不会自动回写已有图纸。
- 无 CAD、无插件或连接中断时保留当前条目，并提供“复制纯文字”。

## 9. 本地数据、交换与备份

- 原始 PDF、资料库、识别结果和页面图片保存在本地管理目录；页面缓存可重建，原文件不能作为缓存清除。
- 云端密钥单独安全保存，不出现在普通日志、导出资料包或错误截图文本中。
- 资料包包含图集、条目、来源、修改记录、文件与校验清单；使用相对路径。
- 导入前预览新增／重复／冲突数量。完全相同内容跳过，不同内容保留副本并标注冲突来源。
- 删除图集前显示关联条目影响；有引用的原文件不得直接物理删除。第一版优先归档条目，避免不可恢复丢失。
- 备份包括一致性的数据库快照和必需原文件；恢复前校验，不直接覆盖工作库。

## 10. 验收要求

| 编号 | 验收场景 | 通过标准 |
| --- | --- | --- |
| A01 | 分类与多词搜索 | 地区、部位、图集组合正确；名称、编号、正文可检索；编号精确匹配排序优先 |
| A02 | 修改与历史 | 修改后搜索和插入使用新正文；旧修订可查看、可恢复；重识别不覆盖修改 |
| A03 | 原文追溯 | 所有从 PDF 入库的条目都能打开正确原页；实际页序与印刷页码不混淆 |
| A04 | 直接入库 | 可解析条目无需审核即可检索与插入；核对状态真实显示 |
| A05 | 恢复与重复 | 重复导入、中途关闭、断网后重试不丢已完成结果，不重复生成已成功条目 |
| A06 | 边界处理 | 一页多条、续页、不明确引用、低清晰页均有可追溯结果或明确异常 |
| A07 | CAD 输出 | 中文、特殊字符和长句可编辑；层次独立；整体移动、取消、撤销与 UCS 定位正确 |
| A08 | 版本兼容 | 2017～2021 逐版本记录实际测试；无运行环境的版本标为待测 |
| A09 | 资料交换 | 另一台电脑导入后可恢复正文、来源和历史；冲突不覆盖；不携带密钥 |
| A10 | 离线使用 | 不联网时可浏览、搜索、编辑、查看已有原页及插入 CAD |

性能与识别试点指标：

- 在记录硬件配置的测试机、1 万条做法数据下，预热后常规搜索的第 95 百分位响应时间目标为 1 秒以内；测试报告记录数据量、查询集合与计时范围。
- 建立至少 100 条人工对照做法，覆盖不同来源、版式和扫描质量。
- 做法拆分准确率与召回率目标均为 95%。准确率按“正确输出条目／全部输出条目”计算，召回率按“正确找回条目／标注条目”计算，匹配规则在评测前固定。
- 材料、数值、单位、否定词和层次顺序单独报告错误率及例子，不用整体字符准确率掩盖关键错误。
- 95% 是待真实样本验证的目标，不是现有能力，也不是工程适用性保证。
